A. Getting this blueprint approved

The route agreed with the advisor. Two steps are gates: nothing is shared before the NDA is signed, and the advisor never receives production source code. Mark each step as you go; the state stays in this browser only.

B. How a client's month is approved inside the product

Who may do what before a month counts as closed. The system checks what it can prove; a person confirms only what it cannot; a difference is closed only by a named person with a reason. Any changed file makes the earlier result stale.

For the advisor: for each stage, say whether the checkpoint is right, whether something is missing, or whether you are unsure, and add a note. Your answers stay in this browser. Use Copy summary to send them back to the team.
