Connect Tally to FynHelp

About 10 minutes, once. Your CA gets your Trial Balance, Profit and Loss and Balance Sheet without asking you for exports every month.

What it does, and what it never does.
  • It reads ledger names, groups and balances from Tally on this PC.
  • It sends them to your CA's FynHelp account over a secure (HTTPS) connection.
  • It never changes anything in Tally. It cannot create, edit or delete a voucher.
  • Nothing connects in to your PC. The agent only sends data out.
  • It does not read bank passwords, GST logins or any file outside Tally.

Before you start

  • A Windows PC where Tally Prime (or Tally.ERP 9) is installed and your company opens.
  • Node.js 18 or newer, free from nodejs.org (choose LTS). Your CA's team can install it on a call.
  • The pairing code your CA gave you, like FYN-7K3Q-9XPA. It works once and expires in 30 minutes; ask for a new one if it lapses.

1. Switch on Tally's local connection

  1. Open Tally Prime and open your company.
  2. Press F1 (Help) → Settings → Connectivity → Client/Server configuration.
  3. Set TallyPrime acts as to Both (or Server) and the port to 9000. Accept.

This only opens Tally to programs on the same PC.

2. Install the agent

  1. Unzip fynhelp-tally-agent.zip to a folder, for example your Desktop.
  2. Double-click Install.bat. If Windows shows a blue "protected your PC" box, choose More info then Run anyway.
  3. When asked, type the pairing code (copy and paste works). The agent pairs, sends the year so far, and sets itself to refresh every 4 hours.

3. Check it worked

Your CA's FynHelp screen shows Connected within a few seconds, and your company appears there for them to link to your file. You do not need to do anything else.

Day to day

  • Keep Tally Prime open on that PC in office hours. If it is closed, the agent simply tries again later.
  • The PC does not need to stay on overnight; it catches up when it is next on.
  • To stop it: your CA can remove the PC in FynHelp, or you can delete the scheduled task FynHelp Tally Sync in Windows Task Scheduler.

If something goes wrong

"Cannot reach Tally": Tally is closed, or step 1 was not saved. Open Tally, repeat step 1.

"No company is open in Tally": open your company, then run again.

"Pairing code is wrong or expired": ask your CA for a new code.

Node.js not found: install Node.js LTS, then run the installer again.

To see what the agent is doing, open Command Prompt in %LOCALAPPDATA%\FynHelpTally and run node agent.mjs status. If your CA asks for a sample, run node agent.mjs diagnose; it saves a file with names replaced that you can read before sending.

Still stuck? Tell your CA, or write to support@fynhelp.com. We can finish the install with you on a short screen-share.
